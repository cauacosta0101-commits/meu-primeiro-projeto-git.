# Material de Estudo - Versão Inicial

- Conceito 1: Versionamento
- É o controle de versões de um projeto, permite salvar o histórico de todas as alterações feitas nos arquivos
 
- Conceito 2: Repositório
- É o local onde o projeto e todo o seu histórico de alterações ficam armazenados
  
- Conceito 3: Commit
- Cada commit registra as mudanças feitas e possui uma mensagem que explica o que foi alterado

- Conceito 4: Branch
- É uma linha paralela de desenvolvimento, permite trabalhar em novas funcionalidades ou correções sem alterar a versão principal do projeto

- Conceito 5: Pull Request
-É uma solicitação de revisão e integração de alterações
